#### 1.2 Dashboard 頁面 (`/admin`)

- [ ] 圓餅圖中心顯示總訊息數
- [ ] 圖例正確顯示各分類百分比與數量
- [ ] 系統健康狀態正常顯示

#### 1.3 對話列表頁面 (`/admin/conversations`)
- [ ] 對話列表正常載入
- [ ] 篩選功能測試：
  - [ ] 使用者 ID 搜尋功能
  - [ ] 關鍵字搜尋功能（搜尋訊息內容）
  - [ ] 開始日期篩選
  - [ ] 結束日期篩選
  - [ ] 組合篩選（多個條件同時使用）
- [ ] 分頁功能正常運作
- [ ] 「查看詳情」按鈕可以正常導向對話詳情頁面

#### 1.4 對話詳情頁面 (`/admin/conversations/detail`)
- [ ] **第一層**：使用者列表正常顯示
  - [ ] 顯示所有使用者的卡片
  - [ ] 每個卡片顯示：使用者 ID、對話數、最後活動時間
  - [ ] 點擊使用者卡片可以進入第二層
- [ ] **第二層**：該使用者的對話列表
  - [ ] 顯示該使用者的所有對話
  - [ ] 每個對話項目顯示：第一條使用者訊息預覽、時間戳記、訊息數量

  - [ ] 使用者訊息顯示：日期時間、內容、分類標籤（如有）

#### 1.5 分類統計頁面 (`/admin/categories`)

## 🚨 常見問題排除

### 問題：管理後台無法載入資料
- 檢查 MongoDB 連線是否正常
- 檢查 API 端點是否正常運作
- 檢查瀏覽器 Console 是否有錯誤

### 問題：圓餅圖無法顯示
- 檢查 Recharts 是否正確安裝
- 檢查資料格式是否正確
- 檢查瀏覽器 Console 是否有錯誤

### 問題：Line Bot 無法回覆
- 檢查 Webhook URL 是否正確設定
- 檢查 Line Channel Access Token 是否正確
- 檢查 Vercel Function Logs 是否有錯誤

### 問題：環境變數未生效
- 確認 Vercel 環境變數已正確設定
- 確認選擇了正確的環境（Production）
- 重新部署專案以套用新的環境變數
