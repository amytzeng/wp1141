LINE Bot Rich Menu 圖片產生器

使用說明

  1. 此頁面顯示 Rich Menu 的設計預覽（尺寸：2500 x 1686 像素，3 列 x 2 行）
  2. 可以下載完整的大圖，或分別下載六張獨立的按鈕圖片
  3. 每張按鈕圖片尺寸約為 833 x 843 像素（第三列為 834 x 843 像素）
  4. 圖片格式：PNG 或 JPEG，檔案大小需小於 1MB
  5. 如果使用截圖，請確保截圖範圍精確包含整個畫布（不包含頁面其他元素）
  6. 將生成的圖片儲存並放在 public/ 目錄下
